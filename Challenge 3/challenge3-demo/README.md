# Challenge 3 Demo

Versao curta e menos tecnica do pitch original, preparada para apresentacao tipo startup product demo com duracao maxima de 5 minutos.

## Objetivo

Mostrar o produto em linguagem de negocio:

- problema claro
- proposta de valor
- demo visual
- impacto operacional
- roadmap curto

## Stack

- React 18
- Vite
- TailwindCSS
- Framer Motion

## Executar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Estrutura de apresentacao (<= 5 min)

1. Hero (20-30s)
2. Problema (45s)
3. Produto (50s)
4. Demo (60-75s)
5. Impacto (60s)
6. Roadmap (40s)
7. Equipa + Fecho (30s)

## Personalizacao rapida

- Conteudo PT/EN: src/i18n/translations.js
- Fluxo de slides: src/App.jsx
- Navegacao: src/components/Navigation.jsx
- Simulacao demo: src/components/Simulation.jsx

## Nota

Esta versao evita detalhe tecnico profundo de modelos e notebooks, focando mensagem comercial e clareza para audiencias nao tecnicas.
